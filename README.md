# مدیریت مالی پیامک‌های بانکی

این پروژه یک دستیار مالی **offline-first و local-only** برای استخراج و تحلیل اطلاعات قابل استفاده از پیامک‌های بانکی است.

## دامنه محصول

SMS فقط منبع «تراکنش» نیست. موتور داده باید بتواند، در صورت وجود اطلاعات کافی در پیام، این موارد را تشخیص دهد:

- تراکنش‌های درآمدی و هزینه‌ای
- انتقال و کارت‌به‌کارت
- مانده گزارش‌شده بانک
- پذیرنده و طرف معامله
- کارمزد
- قبض، شارژ و اقساط
- رویدادهای ناشناخته و نیازمند بررسی
- اطلاعات مرجع/پیگیری و شناسه‌های قابل استفاده برای تطبیق
- الگوهای تکرارشونده و جریان نقدی

معماری استخراج بر پایه `BankAdapter → ParsedBankEvent` است تا فرمت هر بانک مستقل و قابل آزمون باشد. `BalanceObservation` یک موجودیت مستقل از `Transaction` است.

## حریم خصوصی و امنیت

- داده مالی نباید از دستگاه خارج شود.
- هیچ Analytics SDK یا سرویس ابری برای داده مالی مجاز نیست.
- پیام خام و سایر داده‌های حساس باید در لایه native نگهداری و رمزنگاری شوند.
- WebView نباید SMS خام را دریافت کند.
- دسترسی شبکه برای داده مالی نباید اضافه شود.
- تغییر AGP/Kotlin بدون تصمیم معماری و توجیه مکتوب انجام نمی‌شود.

## وضعیت فعلی

نسخه فعلی در حال گذار از مدل اولیه تک‌پارسر به مدل canonical مالی است. مدل‌های زیر برای توسعه مرحله‌ای اضافه شده‌اند:

- `ParsedBankEvent`
- `BalanceObservation`
- `BankAdapter`
- `BankAdapterRegistry`
- `GenericBankAdapter`
- `MerchantAlias`
- `FinancialRule`

این مدل‌ها پایه توسعه بعدی نرمال‌سازی پذیرنده، Rule Engine، تطبیق مانده، اقساط/قبوض/شارژ و گزارش‌گیری هستند.

## ساخت APK

Workflow معتبر GitHub Actions در مسیر `.github/workflows/` قرار دارد.

برای build محلی:
1. پروژه را در Android Studio باز کنید.
2. Gradle Sync را اجرا کنید.
3. از `Build → Build APK(s)` استفاده کنید.

> ساختار پروژه از `App/` استفاده می‌کند؛ مستندات و اسکریپت‌های قدیمی نباید مسیر `app/` را فرض کنند.
